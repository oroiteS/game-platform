# Game Template

复制本目录来创建新游戏。

## 文件职责

```text
game.config.ts       游戏前端元信息
web/                 游戏前端入口和组件
server/              游戏后端规则、状态和事件处理
shared/              该游戏自己的协议说明或共享类型
README.md            该游戏开发说明
```
