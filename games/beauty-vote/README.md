# 美人投票（动态统治版）

**适用人数：4-30人 | 机制亮点：规则相互倾轧，被驱逐的旧神可能卷土重来**

---

## 一、基础规则

- 初始分数 **15分**，扣至0淘汰。
- 每回合秘密选择 **0~100** 整数（首轮禁选0、100）。
- 计算所有有效数字均值 \(\bar{x}\)，目标值 \( T = 0.8 \times \bar{x} \)（保留一位小数）。
- 与 \(T\) 绝对差值最小者获胜（平局共享），不扣分。
- 扣分：
  - 最远 **3名** 各扣2分（存活≤5人时最远1名扣2分）。
  - 其余非获胜者扣1分。
- 全体选择完全相同数字时，无人获胜，全体扣2分。
- 若连续3回合无人淘汰，强制解锁一条规则（从待解锁池抽取）。

### 游戏启动

- 进入房间后为准备阶段（lobby），玩家可点击准备/取消准备。
- 当 **存活人数 == 房间设定人数** 且 **准备人数 == 房间设定人数** 时，自动开始游戏。

---

## 二、动态规则解锁机制

- 初始待解锁池 = {规则1, 规则2, …, 规则10}。池中规则对玩家不可见。
- 解锁频率：
  - **存活 > 10人**：每淘汰 **2人** 解锁一条。
  - **存活 ≤ 10人**：每淘汰 **1人** 解锁一条。
- 解锁时从池中随机抽取一条规则，按域分类生效：
  - **独立域规则**（规则2、4、6、7、9）→ 直接追加，永久叠加。
  - **目标值域规则**（规则5、8、10）→ 若该域已有生效规则，旧规则失效回池，新规则取代之。
  - **胜负替代域规则**（规则1、3）→ 若该域已有生效规则，旧规则失效回池，新规则取代之。
- 被顶替回池的规则可以在此后任何一次解锁中被再次抽中。
- **规则被顶替时需公告全体玩家**（如"规则X已被规则Y取代，回归规则池"）。
- 同一域内最多只有一个规则生效。基础T公式（0.8）不属于规则，可被目标值域规则覆盖，无需回池。

## 三、规则详解

### 独立域（永久叠加）

**规则2：精准奖**
- 若获胜者中有人数字 = round(T)，则本轮非获胜者扣分变为2分（否则正常扣1分）。

**规则4：数字禁区**
- 上回合最终T值四舍五入取整，为本回合禁区数字。选择者立即扣3分，且不能获胜。

**规则6：分数杠杆**
- 提交数字时可勾选"使用杠杆"。若获胜，额外+2分；若未获胜，额外-1分。

**规则7：数字继承**
- 上回合淘汰者所选数字均值（四舍五入）为继承数字。
- 选继承数字的玩家：若获胜，额外+2分；若失败，本回合扣分固定为1分。
- 若上回合无淘汰，继承数字不存在。

**规则9：背叛者**
- 每回合秘密指定一名存活玩家为背叛者（仅本人知）。
- 背叛者本回合目标：成为离T最远的玩家（最远N名之一即可，N=存活≤5时1名、否则3名）。
- 成功：背叛者不扣分，其他所有人额外-1分。
- 失败：背叛者额外-2分。
- 背叛者不可选0、100及禁区数字。
- 若本轮因胜负替代域规则跳过正常最远判定，背叛者无效（不扣分也不加分，回归正常结算）。

### 目标值域（互斥，同一时间仅一生效）

**规则5：反向投票**
- 提交数字时额外提交一个0~100的"反向数字"。
- 众数为 \(R\)（平票取平均四舍五入），T = \( 1.2 \times \bar{x} - R \)，限制在0~100。

**规则8：双重标准**
- 产生两个目标值：\( T_1 = 0.8\bar{x} \)，\( T_2 = 1.2\bar{x} \)。
- 用平方和 \( D = (数字-T_1)^2 + (数字-T_2)^2 \) 判定获胜与最远（D越小越好）。

**规则10：命运轮盘**
- 所有玩家提交后，从 {0.6, 0.8, 1.0} 中随机抽取系数 \(k\)，T = \( k \times \bar{x} \)。

### 胜负替代域（互斥，同一时间仅一生效）

**规则1：镜面惩罚**
- 若存在≥2人选择相同数字，这些玩家投票无效并各扣1分；其他所有玩家立即获胜，不扣分。
- 触发后跳过正常"最接近T"判定。

**规则3：两极跳跃**
- 若本轮有人选0，则所有选100的玩家立即获胜，不扣分。
- 触发后跳过正常T计算与判定。无人选0则不生效。

## 四、特殊事件（每回合15%概率，持续一回合）

- **数字风暴**：所有提交数字在计算均值前随机±5（钳制0-100）。
- **分数重置**：全员分数调整为当前平均分（向上取整，最低5分），原最高分额外+1。
- **匿名失效**：本轮所有选择数字公开。
- **双倍积分**：所有扣分得分翻倍。
- **幸运豁免**：随机一名玩家本轮不扣分。

---

## 五、回合流程

1. **检查解锁**：若淘汰数达标，从待解锁池随机抽取规则，按域处理替换。被顶替规则公告玩家。
2. **特殊事件判定**：15%概率触发，公布事件类型。
3. **收集提交**：时限90秒。提交内容含数字、反向数字（若规则5生效）、杠杆勾选、背叛者目标。
4. **计算T**：依据当前生效的目标值域规则（基础/规则5/8/10）。
5. **胜负替代判定**：检查规则1或规则3是否触发。触发则跳过步骤6。
6. **正常判定**：按正常/D值判定获胜者与最远者。
7. **结算管道**（按以下顺序，不可变更）：
   - ① 禁区惩罚 → ② 继承减伤 → ③ 杠杆修正 → ④ 背叛者调整 → ⑤ 精准奖扣分倍率 → ⑥ 双倍积分（最后）
8. **更新分数**：淘汰≤0者，记录淘汰者数字。
9. **游戏结束判定**：若仅剩1人，游戏结束。

### 回合上限（隐藏规则）

第20回合仍未结束时触发：

- **删除全部动态规则**（独立域、目标值域、胜负替代域），不回池、不公告。
- 规则列表中出现一条 **"隐藏规则"**（前端可见其存在，但**不可查看具体内容**）。
- 隐藏规则的实际效果（仅后端执行）：
  - 全员分数减半（向下取整）。
  - T 永久设为 0。
- 此后所有回合 T=0，无动态规则生效。

## 六、结算管道详解（顺序不可变）

```
① 禁区惩罚：选了禁区数字 → -3，标记"不能获胜"
② 继承减伤：选了继承数字且未获胜 → 本回合扣分固定为1（覆盖后续扣分基数）
③ 杠杆修正：勾选杠杆 → 获胜+2 / 未获胜-1
④ 背叛者调整：成功 → 不扣分且全员-1 / 失败 → 额外-2 / 胜负替代触发 → 无效
⑤ 精准奖倍率：round(T)在获胜者中 → 非获胜者扣分 1→2（不影响最远者扣分2）
⑥ 双倍积分：所有扣分/加分 ×2（特殊事件，最后触发）
```

## 九、快照设计要点

- **提交阶段**：玩家只能看到自己的提交，其他人的数字不可见。
- **结算阶段（reveal）**：公开所有玩家数字、T值、获胜者、最远者、扣分明细—仅在游戏结束时完全展示。**常规 reveal 阶段仅展示每个玩家的胜负状态和自身数字，其他玩家的具体数字在游戏最终结束时才全部公开。**
- 背叛者目标仅自己可知，结算时公开背叛结果。
- **规则池内容对所有玩家不可见**。仅当前已生效的规则可通过规则面板查看。
- 回合上限模式（20回合后）的状态变更不向前端暴露原因。
